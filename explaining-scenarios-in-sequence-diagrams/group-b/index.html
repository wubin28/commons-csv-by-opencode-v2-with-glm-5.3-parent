B1取不存在的列名 → IllegalArgumentException，消息带 "expected one of" headerMap 非空但查不到 key 时的异常类型，与 A1 的 headerMap == null → IllegalStateException 形成分界。 getByNameWithUnknownNameThrowsMappingNotFound（:143-149） B2a表头列数多于记录列数 → 按名取不到的列先数组越界、再转换成 Index 消息 isConsistent() 为 false；"先越界、再转换成新异常"是两个独立步骤，不是一步直接抛错。 headerLongerThanRecordThrowsIndexMessage（:153-161） B2b记录列数多于表头列数 → 已映射列仍可正常取值（对照 B2a） 多出来的值照常存进记录，isConsistent() 同样为 false，但方向与 B2a 相反：这里是数据比表头长。 recordLongerThanHeaderIsInconsistentButReadable（:165-171） B3a仅表头行，没有任何数据行 → 数据记录为空，headerMap / headerNames 仍完整 表头的世界在 CSVParser 构造期就已定案，与之后到底有没有数据行完全独立。 headerOnlyFileYieldsNoRecordsButHeaderMap（:175-181） B3b完全空文件 + 自动探测表头 → headerMap 是空 Map，不是 null createEmptyHeaderMap() 在更早的步骤就已经把 Map 对象建好了——headerMap == null 与"空 Map"是两种不同的退化形态。 emptyFileWithAutoDetectedHeaderYieldsEmptyHeaderMap（:185-191）
